# CRUD de Productos - Laravel y PostgreSQL

Proyecto desarrollado como práctica integradora de un sistema **CRUD (Create, Read, Update, Delete)** utilizando el framework **Laravel 11**, base de datos relacional **PostgreSQL** y diseño responsivo con **Bootstrap 5**.

---

##  Características 

* **Gestión completa de productos:** Permite registrar, visualizar, actualizar y eliminar productos de la base de datos de manera dinámica.
* **Base de datos PostgreSQL:** Conexión robusta configurada mediante variables de entorno (`.env`).
* **Seeder de Datos (Reto 4):** Implementación de seeders (`DatabaseSeeder` y `ProductoSeeder`) para poblar automáticamente la base de datos con un catálogo inicial de 10 productos de prueba.
* **Interfaz amigable:** Estilizado con Bootstrap para una navegación limpia y accesible.

---

## Tecnologías y Herramientas Utilizadas

* **PHP 8.2+** / **Laravel 11**
* **PostgreSQL** (Base de datos)
* **Blade Templates** (Motor de plantillas)
* **Bootstrap 5** (Diseño de interfaces)
* **Git y GitHub** (Control de versiones)
